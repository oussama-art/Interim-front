# Images à télécharger

## 📸 Images nécessaires pour l'application

Téléchargez les images suivantes et placez-les dans ce dossier :

### 1. **candidate-bg.jpg** (Image pour les candidats)
- **Sources recommandées** :
  - Pexels : https://www.pexels.com/search/office%20work/
  - Pixabay : https://pixabay.com/images/search/business%20person/
  - Unsplash : https://unsplash.com/s/photos/professional-worker

- **Critères** :
  - Résolution : 1920x1080 minimum
  - Format : JPG ou PNG
  - Taille : < 500KB (optimisée)
  - Thème : Personne travaillant sur ordinateur, ambiance professionnelle

### 2. **client-bg.jpg** (Image pour les entreprises)
- **Sources recommandées** :
  - Pexels : https://www.pexels.com/search/business%20meeting/
  - Pixabay : https://pixabay.com/images/search/office%20team/
  - Unsplash : https://unsplash.com/s/photos/business-team

- **Critères** :
  - Résolution : 1920x1080 minimum
  - Format : JPG ou PNG
  - Taille : < 500KB (optimisée)
  - Thème : Équipe en réunion, bureau moderne, collaboration

### 3. **register-bg.jpg** (Image pour l'inscription)
- **Sources recommandées** :
  - Pexels : https://www.pexels.com/search/modern%20office/
  - Pixabay : https://pixabay.com/images/search/startup/

## 🎨 Suggestions de recherche :

### Pour Pexels (gratuit, sans attribution requise) :
1. Allez sur https://www.pexels.com
2. Recherchez :
   - "office worker computer" pour candidate-bg.jpg
   - "business team meeting" pour client-bg.jpg
   - "modern office space" pour register-bg.jpg
3. Téléchargez en résolution "Large" ou "Original"
4. Renommez selon les noms ci-dessus

### Pour Pixabay (gratuit, sans attribution requise) :
1. Allez sur https://pixabay.com
2. Recherchez les mêmes termes
3. Téléchargez en haute résolution
4. Renommez selon les noms ci-dessus

### Pour Unsplash (gratuit, attribution optionnelle) :
1. Allez sur https://unsplash.com
2. Recherchez les mêmes termes
3. Cliquez sur "Download free"
4. Renommez selon les noms ci-dessus

## 🔧 Optimisation des images (optionnel mais recommandé) :

- Compressor.io : https://compressor.io/
- Squoosh : https://squoosh.app/
